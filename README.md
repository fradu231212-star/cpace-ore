# Space Ore — Minecraft 1.21.1 / NeoForge

Космическая руда и предметы для Minecraft Java 1.21.1 на NeoForge.

## Содержимое
- Cosmic Ore генерируется в Энде.
- Raw Cosmic Ore → Cosmic Ingot через печь.
- Cosmic Block.
- Cosmic Sword, Cosmic Blade, Cosmic Pickaxe.
- Cosmic Shard, Cosmic Crystal, Star Core.
- Русский и английский перевод.

## Как получить один готовый JAR
Нужен **64-битный Java 21**. NeoForge для Minecraft 1.21.1 использует Java 21.

### Windows
1. Распакуй ZIP.
2. Дважды нажми `build.bat`.
3. Первый запуск скачает Gradle и зависимости NeoForge — это может занять время.
4. Готовый файл появится здесь:
   `build\\libs\\spaceore-1.0.0.jar`
5. Положи этот JAR в папку `mods` Minecraft 1.21.1 с NeoForge.

### Linux/macOS
```bash
./build.sh
```

После сборки JAR будет в `build/libs/spaceore-1.0.0.jar`.

## Важно
Мод рассчитан на NeoForge 21.1.x и Minecraft 1.21.1. Не клади его в Forge/Fabric-профиль.
